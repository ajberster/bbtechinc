BBTECH INC. CLEAN VECTOR PRODUCTION PACKAGE

This package replaces the earlier raster-traced export set.

The artwork is derived from the exact approved logo-book master, separated into a true one-color silhouette, cleaned of raster edge noise, and stored as scalable SVG paths.

Use:
- SVG masters for print, signs, apparel, engraving, and future exports.
- 1024/2048 PNGs for high-resolution raster use.
- Smaller PNGs for web/UI.
- Transparent PNGs when the background is supplied elsewhere.

Treat the SVG files in 01_Vector as the source masters for future production.
